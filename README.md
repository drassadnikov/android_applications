# Дзен.Новости — standalone-виджет (без приложения Дзен)

Стandalone-проект: виджет «Дзен.Новости» + компактный companion-экран
настройки (MainActivity) — сам Дзен не нужен. Пакет `ru.zen.android.widget`,
сосуществует с оригинальным Дзен (`ru.zen.android`).

## Что умеет виджет (v18.5)
- **Тематики с горизонтальным скроллом**: полоса вкладок
  (Главное, [Регион 1], [Регион 2], Свежее, СВО, Спорт, Шоу-бизнес,
  Происшествия, Авто, Политика, Общество, Экономика, В мире, Культура,
  Технологии, Наука) — 4 вкладки на страницу, листаются стрелками.
- **Шапка: курсы ЦБ РФ + ключевая ставка**: `Обновлено HH:mm • USD xx.xx▲/▼
  • EUR xx.xx▲/▼ • КС xx.xx%▲/▼`. Ключевая ставка — с
  `https://cbr.ru/hd_base/KeyRate/` (первая строка HTML-таблицы), стрелки —
  сравнение с предыдущим значением из кэша. CNY убран.
- **До 2 региональных вкладок, как в веб-Дзене**: регион №1 по умолчанию
  «Абакан», №2 — опционально (например, «Чебоксары»). Лента — реальный API
  Дзен `rubric?region=<алиас>`, кэш отдельно под каждым регионом
  (`feed_cache_v18b_region_<алиас>`).
- **Ввод региона кириллицей** в companion-приложении: «Абакан», «Москва»,
  «Ростов-на-Дону» — приложение само переводит в латинский алиас Дзен
  (карта `CITY_ALIASES`: Абакан → Abakan, Москва → Moscow,
  Ростов-на-Дону → Rostov-na-Donu). Поля настроек и вкладки показывают
  кириллицу (официальное имя региона из API Дзен), алиас хранится внутри.
- **Живые логотипы источников, как в Дзен**: API отдаёт `doc.logo_square`,
  рабочий URL = `logo_square + "/logo-square"` (поле `logo` с `-regular`
  отдаёт 404). Иконки предзагружаются фоном в кэш-файлы, виджет рисует из
  файлов. Fallback: 25 статичных PNG (`drawable-nodpi/src_*.png`) →
  бренд-метка «RT»/«В»/«МК» с фирменным цветом (`SOURCE_STYLE`).
- **Кнопка «Обновить» (⟳) в шапке**: broadcast `WIDGET_REFRESH` →
  счётчик в `WidgetPrefs` → лента визуально перестраивается.
- **Заголовки в 2 строки без обрезки**: шрифт 8sp, `maxLines=2`.
- **Вертикальный скролл ленты**: `ListView` с `scrollbars="vertical"`,
  читается вся «простыня».
- **Оригинальный логотип Дзен** (цветная «искра» с градиентом) —
  иконка приложения и шапка виджета.
- Клик по шапке — dzen.ru в браузере; клик по новости — URL в браузере
  (переход через `ACTION_VIEW`).

## 1. Собрать APK

Gradle 8.9 (локально:
`C:\Users\HOME-PC\.gradle\wrapper\dists\gradle-8.9-bin\90cnw93cvbtalezasaz0blq0a\gradle-8.9\bin\gradle.bat`):

```
gradle.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## 2. Подписать тем же ключом, что и предыдущие версии

```
apksigner.bat sign ^
  --ks ..\dzen-widget-v6.keystore ^
  --ks-pass pass:dzen12345 --ks-key-alias dzen --key-pass pass:dzen12345 ^
  --out ..\Дзен.Новости_виджет_v18.apk app-debug.apk
```

`versionCode = 309273559` (versionName 18.5; выше, чем у Дзен 26.10.2 =
309273550), поэтому при совпадении подписи установка идёт как апгрейд.

## 3. Установить на телефон

```
adb install ..\Дзен.Новости_виджет_v18.apk
```

Если на телефоне стоит Дзен, подписанный **другим** ключом
(например, пере-подписанная VK Store-версия), сначала:
`adb shell pm uninstall ru.zen.android` — виджет придётся переставить.

## 4. Поставить виджет

На главном экране: **долгое нажатие по пустому месту → Виджеты →
«Дзен.Новости»** → перетащить на экран. Размер 4×4 (можно растягивать).

## Структура кода

```
app/src/main/java/ru/zen/android/widget/
├── DzenNewsWidgetProvider.kt   # шапка, «Обновить», вкладки, список
├── DzenNewsWidgetService.kt    # RemoteViewsService
├── DzenNewsWidgetFactory.kt    # строки ленты + логотипы + клик → браузер
├── NewsRepository.kt           # вкладки, 2 региона, API Дзен, кэш, иконки
├── RatesRepository.kt          # курсы ЦБ РФ + ключевая ставка (cbr.ru)
├── MainActivity.kt             # companion: курсы, ключевая ставка, 2 региона
├── NewsItem.kt                 # модель
└── WidgetPrefs.kt              # вкладки, регионы, счётчик «Обновить»

app/src/main/res/
├── layout/dzen_news_widget.xml # шапка + полоса вкладок + ListView
├── layout/dzen_news_item.xml   # аватар + заголовок 8sp/2 строки + метка
├── layout/activity_main.xml    # экран companion-приложения
├── drawable/dzen_logo.xml      # оригинальный логотип Дзен (искра)
├── drawable/dzen_avatar_*.xml  # круглые аватары
├── drawable/src_bg_*.xml       # 9 фирменных фонов бренд-меток
├── drawable-nodpi/src_*.png    # 25 статичных логотипов источников
└── xml/dzen_news_widget_info.xml
```
